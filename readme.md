# 🚗 Vehicle Rental System

## 📌 About the Project
Vehicle Rental System is a web-based application developed using Python, Streamlit, and MySQL.

This project helps users manage vehicle rentals, customers, bookings, payments, returns, and maintenance records in one place.

## 🎯 Project Objective
The main objective of this project is to reduce manual work and make vehicle rental management simple, easy, and efficient.

## 🛠️ Technologies Used
- Python
- Streamlit
- MySQL
- MySQL Connector
- Pandas

## ✨ Features
- Login and Registration
- Customer Management
- Vehicle Management
- Vehicle Booking
- Payment Management
- Vehicle Return Management
- Maintenance Management
- Employee Management
- Branch Management
- Dashboard and Reports

## 🗄️ Database Tables
- Branch
- Customer
- Vehicle
- Employee
- Booking
- Payment
- Return
- Maintenance

## ⚙️ Installation

Install the required packages:

```bash
pip install streamlit mysql-connector-python pandas
```

## ▶️ How to Run

1. Open MySQL.
2. Execute the BACKEND.sql file.
3. Configure the database connection in app.py.
4. Open Command Prompt in the project folder.
5. Run:

```bash
streamlit run app.py
```
